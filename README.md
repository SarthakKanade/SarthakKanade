## ⚔️ MAIN QUEST: SHOOTOPIA

> **Multiplayer 3D Arena Shooter** built in **Unity 6** with **Netcode for GameObjects**

| | |
|---|---|
| 🌐 **Networking** | Server-authoritative. Unity Relay + Lobby for matchmaking and join-by-code, LAN discovery as offline fallback |
| 🛡️ **Anti-cheat mindset** | Health and shield live in `NetworkVariable`s, so clients can't modify them. Combat is server-validated |
| 🎯 **Modes** | Free-For-All and Team Deathmatch with scoring and leaderboards |
| 🏃 **Movement** | Hierarchical state-machine controller: locomotion, dash, roll, jump |
| 🔫 **Arsenal** | Modular partial-class weapon system: elemental weapons, ricochet projectiles, throwables, trip mines, tiered loot crates |
| ⚡ **Performance** | Global object pooling for projectiles and VFX |
| 📦 **Shipped on** | Windows, macOS, WebGL, Android with an adaptive keyboard/mouse + touch input layer |
